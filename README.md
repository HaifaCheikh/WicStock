# WicStock – Smart Textile Inventory Management Platform

## Overview

WicStock is a smart web-based inventory management platform designed for the textile industry with a strong focus on **waste reduction** and **inventory optimization**.

The application helps companies efficiently manage products, inventory movements, production, and sales while predicting inventory risks such as **overstock**, **stock shortages**, and **product obsolescence**. It also recommends appropriate actions such as promotions, redistribution, or recycling to minimize waste.

The project is built using **ASP.NET Core (.NET 8)** for the backend and **Blazor WebAssembly** for the frontend.

---

## Technology Stack

### Backend

* ASP.NET Core Web API (.NET 8)
* Entity Framework Core
* SQL Server
* JWT Authentication

### Frontend

* Blazor WebAssembly
* MudBlazor

### External Services

* Cloudflare Turnstile
* WhatsApp API

## Installation

### Clone the repository

```bash
git clone https://github.com/HaifaCheikh/WicStock
```

### Restore dependencies

```bash
dotnet restore
```

### Build the solution

```bash
dotnet build
```

## Running the Application

Run the backend:

```bash
dotnet run
```

Then start the Blazor WebAssembly client.

Or simply launch the solution from **Visual Studio 2022**.
